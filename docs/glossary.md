# Глоссарий

| Термин | Описание |
|--------|----------|
| **Автомобиль** | Транспортное средство автопарка, имеющее номер, марку, пробег и грузоподъёмность. |
| **Водитель** | Сотрудник автопарка, управляющий автомобилем. Имеет табельный номер, стаж, категорию и адрес. |
| **Заказ** | Перевозка груза на определённое расстояние определённым автомобилем и водителем. Включает дату, километраж, массу груза и стоимость. |
| **Грузоподъёмность** | Максимальная масса груза, которую может перевезти автомобиль. |
| **Заработок водителя** | 20% от стоимости перевозки. |
| **Менеджер** | Пользователь с полными правами на управление данными и формирование отчётов. |
| **Аутентификация** | Проверка логина и пароля для доступа к системе. |
