# Функциональные требования


## Текстовый сценарий: «Просмотр водителем своих заказов за период»

1. Водитель входит в систему (логин/пароль).
2. Система определяет роль «водитель».
3. Водитель выбирает пункт меню «Мои заказы за период».
4. Система запрашивает начальную и конечную дату.
5. Водитель вводит даты.
6. Система выполняет запрос к базе данных и выводит список заказов.
7. Сценарий завершается.

## Перечень функциональных требований

- Аутентификация пользователей (водитель, менеджер).
- CRUD (создание, чтение, обновление, удаление) для автомобилей, водителей, заказов.
- Отчёт по водителю за указанный период.
- Отчёт по автомобилю (общий пробег и масса грузов).
- Отчёт по каждому водителю (поездки, масса, заработок).
- Поиск водителя с наименьшим количеством поездок.
- Поиск автомобиля с наибольшим пробегом.
- Проверка грузоподъёмности при создании заказа.
- Расчёт заработка всех водителей за период.
- Расчёт заработка указанного водителя за период.
