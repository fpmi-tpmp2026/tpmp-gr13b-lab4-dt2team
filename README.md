# Project Name: Автопарк

## Description

Консольное приложение на языке C для управления автопарком.  
Позволяет вести учёт автомобилей, водителей и заказов на перевозку грузов, формировать отчёты и автоматически рассчитывать заработную плату водителей (20% от стоимости перевозки).  
Реализована аутентификация с разделением ролей: менеджер имеет полный доступ, водитель видит только свои данные.  
Проект включает непрерывную сборку и тестирование (GitHub Actions), проверку покрытия кода (Codecov) и полную документацию (Wiki, UML-диаграммы).

## Installation

### Требования

- Компилятор GCC (MinGW под Windows, GCC под Linux/macOS)
- SQLite (статическая амальгама включена в проект)
- Make (опционально)

### Шаги для установки и сборки

1. Клонируйте репозиторий с кодом:
   ```bash
   git clone https://github.com/ignatmuray/tpmp-lab4-code.git
   cd tpmp-lab4-code
   ```

2. Скомпилируйте проект:
   ```bash
   gcc src/*.c sqlite3.c -Iincludes -o autopark.exe
   ```
   (на Linux/macOS замените `autopark.exe` на `autopark`)

3. Запустите приложение:
   ```bash
   ./autopark.exe   # Windows
   ./autopark       # Linux/macOS
   ```

## Usage

После запуска программа попросит ввести логин и пароль.  
Используйте учётные данные:

| Роль      | Логин     | Пароль   |
|-----------|-----------|----------|
| Менеджер  | `manager` | `pass123`|
| Водитель  | `ivanov`  | `pass123`|
| Водитель  | `petrov`  | `pass123`|

**Меню менеджера** позволяет:
- Управлять автомобилями, водителями, заказами (CRUD)
- Формировать отчёты (по водителю за период, по машине, общая статистика, водитель с минимум поездок, машина с максимум пробега)
- Рассчитывать заработок всех водителей или указанного водителя за период

**Меню водителя** предоставляет:
- Просмотр своих заказов за период
- Данные о своей машине
- Личную статистику (количество поездок, перевезённая масса, заработанная сумма)
